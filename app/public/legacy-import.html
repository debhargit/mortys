Import from the old system

SystemAdmin

1. The export files

Export from the old program as CSV: INVENTRY (stock), INVOICE (invoices), INVDETAI (items sold), INVPAY (payments) and INVREC (stock received). Any of the five can be imported on its own. Either put them in a folder on the till PC, or upload them from this computer.

2. Check, then import

Check reads the files and says what an import would change, without changing anything. Import then brings across only what is new: new parts, invoices, payments and stock received, and the stock on hand, cost and price of parts the old program has changed. Names, categories, groups and anything done in this system stay as they are, and the same files can be imported again without anything coming in twice. A large import takes several minutes; the till keeps working meanwhile.
